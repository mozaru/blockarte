# Identidade visual — Blockmarte

Kit alinhado à família 11Tech (11CodeClass, 11CodeForge, 11AgentFit). Textos dos SVGs convertidos em curvas (fonte Outfit), sem dependência de fonte instalada.

| Pasta | Conteúdo |
| --- | --- |
| `svg/` | logo vertical/horizontal (cor, negativo, negativo transparente), símbolo (cor, branco, preto, fundo escuro), ícone de app, maskable e favicon |
| `png/` | logos e símbolo em alta resolução |
| `icons/` | `favicon.ico`, favicon 16/32/48, `apple-touch-icon` 180, ícones 64–1024 e maskable 192/512 |
| `banners/vetorial/` | Open Graph 1200x630, GitHub social 1280x640, hero 1920x640, post 1080x1080, story 1080x1920 (SVG + PNG) |

Paleta: tinta `#1c1917`, marca `#dc2626`, tom claro `#f97316`, acento `#22d3ee`, fundo escuro `#120a0a`.
